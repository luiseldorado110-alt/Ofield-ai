# Ofield AI

Primera versión de Ofield AI, una web para organizar ideas y convertirlas en estructuras de proyectos.

## Publicar con GitHub Pages

1. Abre **Settings → Pages**.
2. En **Build and deployment**, selecciona **Deploy from a branch**.
3. Selecciona `main` y la carpeta `/ (root)`.
4. Pulsa **Save**.
5. GitHub publicará el sitio en una dirección parecida a `https://luiseldorado110-alt.github.io/Ofield-ai/`.

Esta versión no necesita servidor ni API.
